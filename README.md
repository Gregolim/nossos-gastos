# 💰 Nossos Gastos

App simples para o casal controlar o dinheiro junto.

## O que dá pra fazer

- 🧾 **Contas**: anotar gastos e contas a pagar, inclusive parceladas
- 🏷️ **Categorias**: separar os gastos por tipo (mercado, casa, lazer...)
- 📊 **Painel**: ver gráficos de para onde o dinheiro está indo
- 🐷 **Reservas**: guardar dinheiro para emergências
- 🌟 **Sonhos**: juntar dinheiro para objetivos (viagem, casa, carro...)

## Como funciona

- Abre no navegador do computador ou do celular e pode ser **instalado como app**
- Os dois veem **os mesmos dados em tempo real**
- Só entra quem fizer **login com o Google** usando um dos e-mails do casal
- Funciona até **sem internet** e sincroniza depois
